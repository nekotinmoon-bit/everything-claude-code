# Snail Mod (Forge 1.21.1)

Добавляет в игру **улитку**: медленного мирного моба из болот и лесов.

- Если её ударить, прячется в раковину на 5 секунд: не двигается и получает только 25% урона.
- Размножается грибами (красными и коричневыми), за грибом в руке ползёт следом.
- Дроп: 0–1 слизь (больше с «Добычей»), с шансом 15% раковина, если убил игрок.
- Раковину можно скрафтить в 4 костной муки.
- Спавнится в лесах (`#minecraft:is_forest`), болотах и мангровых болотах.

## Сборка

Нужны JDK 21 (под игру), а ещё JDK 25 и JDK 8: их требует ForgeGradle 7 при первой настройке.

```
./gradlew build              # готовый мод: build/libs/snailmod-1.0.0.jar
./gradlew runClient          # запустить игру с модом
./gradlew runGameTestServer  # игровые тесты (src/main/java/com/snailmod/gametest)
```

Положи jar в папку `mods` профиля Forge 1.21.1 (52.1.21 или новее).
